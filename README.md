# Biblio_LLM

Десктопний застосунок для пошуку, ранжування, збереження та експорту наукових статей з arXiv, PubMed і Semantic Scholar.

## 📌 Загальна інформація

- **Тип проєкту**: десктопний застосунок
- **Мова програмування**: C++17
- **Інтерфейс користувача**: Qt Widgets
- **Система збірки**: CMake
- **Тестування**: GoogleTest, CTest
- **Джерела даних**: arXiv, PubMed, Semantic Scholar
- **Методи ранжування**: локальна нейронна модель і TF-IDF
- **Результати бенчмарків**: CSV-таблиці, графіки PNG та SVG

Проєкт розроблено як бакалаврська дипломна робота на тему аналізу бібліографічних джерел за допомогою підходів на основі мовних моделей. Система отримує наукові статті з публічних академічних джерел, приводить їх до уніфікованого внутрішнього представлення, ранжує локально та надає інструменти для збереження й експорту бібліографічних записів.

---

## 🧠 Опис функціоналу

- Пошук наукових статей через arXiv, PubMed і Semantic Scholar.
- Завантаження результатів порціями по 50 статей і переранжування накопиченого списку після прокрутки.
- Порівняння двох режимів ранжування: локальна нейронна модель і TF-IDF.
- Перегляд назви, авторів, дати публікації, DOI, URL, журналу та анотації статті.
- Збереження вибраних статей локально у форматі JSON.
- Експорт бібліографічних записів у форматах PlainText, BibTeX і RIS.
- Навчання локальної моделі ранжування на основі TSV-датасету.
- Запуск бенчмаркових експериментів і генерація графіків для дипломної роботи.
- Автоматизоване тестування математичних операцій, токенізації, ембедингів, уваги та трансформерних блоків.

## 🛠️ Як зібрати проєкт з нуля

### 1. Необхідні інструменти

- Компілятор C++ з підтримкою C++17
- CMake 3.20 або новіший
- Qt 5.15.1 для MSVC 2019 64-bit
- Python 3 з `pandas` і `matplotlib` для побудови графіків бенчмарків

> **Важливо — Qt має бути встановлений за точним шляхом, інакше CMake завершиться з помилкою:**
>
> ```text
> C:/Qt/Qt5.15.1/5.15.1/msvc2019_64
> ```
>
> І `CMAKE_PREFIX_PATH` (для `find_package`), і команда `windeployqt` після збірки в `CMakeLists.txt` посилаються на цей шлях напряму.
> Якщо Qt встановлено в іншому місці, потрібно оновити **обидва** рядки в `CMakeLists.txt`:
>
> ```cmake
> set(CMAKE_PREFIX_PATH "C:/Qt/Qt5.15.1/5.15.1/msvc2019_64")
> # ...
> COMMAND "C:/Qt/Qt5.15.1/5.15.1/msvc2019_64/bin/windeployqt.exe"
> ```

### 2. Клонування репозиторію

```bash
git clone https://github.com/OlexandrProkopovich/Biblio_LLM.git
cd Biblio_LLM
```

### 3. Конфігурація та збірка

```bash
cmake -S . -B build
cmake --build build --config Release
```

Після збірки головного застосунку автоматично виконується `windeployqt`, який копіює необхідні Qt runtime файли для Windows.

### 4. Запуск застосунку

```bash
build/Release/LLM
```

На Windows виконуваний файл знаходиться в:

```text
build/Release/
```

## 🤖 Навчання моделі

Модель можна навчити на локальному TSV-датасеті. Кожен рядок має містити або:

```text
запит<TAB>назва<TAB>анотація
```

або:

```text
запит<TAB>текст
```

Приклад команди:

```bash
build/Release/LLM_Train --dataset tools/dataset.tsv --max-pairs 1000000 --epochs 5 --batch-size 1024 --threads 4 --output model.bin
```

Доступні параметри:

| Параметр | Значення |
|---|---|
| `--dataset` | Шлях до TSV-датасету для навчання. |
| `--max-pairs` | Максимальна кількість навчальних пар для вибірки. |
| `--epochs` | Кількість епох навчання. |
| `--batch-size` | Розмір міні-батчу. |
| `--threads` | Кількість робочих потоків. |
| `--output` | Вихідний файл моделі. |
| `--dmodel` | Розмірність ембедингу. |
| `--dk` | Розмірність ключа уваги. |
| `--dff` | Розмірність прихованого шару прямого поширення. |

Великі датасети та файли навченої моделі навмисно виключені з Git.

## 📊 Запуск бенчмарків

Перед запуском переконайтеся, що файл `model.bin` знаходиться в кореневій директорії проєкту (поруч з `CMakeLists.txt`). Якщо навчали модель командою `LLM_Train`, вона за замовчуванням зберігається саме там.

Запуск усього набору бенчмарків:

```bash
build/Release/Benchmark model.bin tools/dataset.tsv 1000
```

Запуск лише бенчмарку стійкості токенізатора:

```bash
build/Release/Benchmark model.bin tools/dataset.tsv 1000 bench4
```

Генерація графіків бенчмарків:

```bash
python scripts/plot_benchmarks.py benchmarks benchmarks
```

Згенеровані файли зберігаються в:

```text
benchmarks/
```

Основні групи бенчмарків:

- Якість ранжування: нейронна модель проти TF-IDF.
- Затримка переранжування: нейронна модель проти TF-IDF.
- Швидкість токенізації: словниковий токенізатор проти BPE.
- OOV-слова проти фрагментації BPE.
- Час навчання та прискорення залежно від кількості потоків.
- Крива втрат під час навчання.

## 🖱️ Інструкція для користувача

1. Запустіть головний застосунок.
2. Введіть пошуковий запит, наприклад `machine learning`.
3. Оберіть джерело: arXiv, PubMed або Semantic Scholar.
4. Оберіть режим ранжування: нейронна модель або TF-IDF.
5. Натисніть **Search**.
6. Прокручуйте вниз для завантаження нових результатів. Накопичений список статей переранжовується після кожної порції.
7. Використовуйте **Save** для збереження вибраної статті локально.
8. Відкрийте вкладку збережених статей для перегляду.
9. Використовуйте кнопки експорту для генерації записів у форматах PlainText, BibTeX або RIS.

Збережені статті зберігаються у форматі JSON у директорії даних застосунку Qt:

```text
<AppDataLocation>/saved/
```

На Windows це, як правило:

```text
C:/Users/<user>/AppData/Roaming/LLM/saved/
```

## 🧪 Поширені проблеми та рішення

| Проблема | Можливе рішення |
|---|---|
| CMake не знаходить Qt | Qt має бути встановлений за шляхом `C:/Qt/Qt5.15.1/5.15.1/msvc2019_64`. Якщо встановлено в іншому місці — оновіть `CMAKE_PREFIX_PATH` і шлях до `windeployqt` у `CMakeLists.txt`. |
| Застосунок запускається, але відсутні Qt DLL | Перезберіть ціль `LLM`, щоб виконалася команда `windeployqt`. |
| Модель не завантажується | Покладіть `model.bin` у кореневу директорію проєкту (поруч з `CMakeLists.txt`) або передайте явний шлях першим аргументом. |
| Бенчмарк завершується з помилкою пам'яті | Використовуйте меншу модель або запустіть конкретний режим бенчмарку, наприклад `bench4`. |
| Результати пошуку не відображаються | Перевірте підключення до інтернету та обране джерело даних. |
| Збережені статті не відображаються | Перевірте директорію даних застосунку в папці `saved/`. |
